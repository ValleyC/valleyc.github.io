# Ruogu Chen's Academic Homepage

Public academic homepage of Ruogu Chen, PhD candidate at the University of Alberta.

## Website

https://valleyc.github.io/

The site is static and has no analytics or backend services. GitHub Pages serves
the root directory of the `main` branch. Push updates to `main` to publish them.
The `.nojekyll` file disables Jekyll processing.

## Files

- `index.html`: biography, six publications, teaching, and contact information.
- `styles.css`: responsive layout and light and dark themes.
- `site.js`: navigation, publication search, filters, and citation tools.
- `assets/references.bib`: downloadable bibliography.
- `assets/ruogu-chen.jpg`: public profile photograph.
- `assets/lucide.min.js` and `assets/lucide.LICENSE.txt`: icon library and license.
